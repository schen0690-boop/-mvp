七、结果未知、失败和暂停处理

浏览器断线、截图失败或控制响应丢失：

不得再次创建、开始或重新生成。

允许重新连接SSE、GET、刷新和只读检查，
这些操作不能触发模型请求。

用户结束或控制请求结果未知时：
先核对服务器状态，再按既有幂等契约处理；
不能反复点击来猜测结果。

生成内容或提炼失败：
按既有运行规则决定跳过、有限重试或收尾，
所有请求计入同一预算。
本轮不得临时改提示词后重新开始一场。

总结失败：
保留completed + summary.unavailable的真实降级结果，
不伪造正文，也不在run结束后补调一次总结。

致命故障、进程异常或无法核实状态时：
停止新的模型派发，保留数据库和预算证据；
明确报告失败或受阻，不以Fake替换真实结果。

真实run开始后的问题可以在关闭授权后
